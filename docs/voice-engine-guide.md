# Полное руководство: Voice Engine (Groq Whisper STT + Orpheus / Kokoro TTS)

> **Статус:** Нормативная эталонная документация  
> **Компоненты:** `src/lib/voiceEngine.ts`, `src/components/ChatInput.tsx`, `src/components/ContextSidebar.tsx`, `src/components/SettingsModal.tsx`

---

## 1. Что такое Voice Engine и из чего он состоит?

**Voice Engine** — это встроенный в экосистему аудио-конвейер для полноценного двустороннего голосового общения с искусственным интеллектом в реальном времени.

Он состоит из двух независимых подсистем:
1. **STT (Speech-to-Text / Распознавание речи)** — слушает ваш голос через микрофон и превращает его в текст с помощью сверхбыстрого облака **Groq Whisper** или локальной модели.
2. **TTS (Text-to-Speech / Синтез речи)** — берет текстовый ответ языковой модели, очищает его от системных тегов, нарезает на предложения и озвучивает естественным человеческим голосом через **Orpheus / Kokoro TTS** (с автоматическим бесшовным переключением на **Web Speech API** браузера при отсутствии сети).

## 2. Архитектура и принцип работы STT (Groq Whisper)

```
[ Пользователь зажимает микрофон / Пробел ]
                    │
                    ▼
[ Браузер: MediaRecorder API (audio/webm;codecs=opus) ]
                    │
                    ▼
[ Пользователь отпускает кнопку (минимум 2 сек) ]
                    │
                    ▼
[ HTTP POST -> https://api.groq.com/openai/v1/audio/transcriptions ]
      - Заголовок: Authorization: Bearer <GROQ_API_KEY>
      - FormData: file (speech.webm), model: whisper-large-v3
                    │
                    ▼
[ Ответ Groq LPU за ~150-300 мс: { "text": "Ваш вопрос..." } ]
                    │
                    ▼
[ Текст мгновенно вставляется в поле ввода или сразу отправляется в чат ]
```

### Преимущества Groq Whisper:
- **Скорость:** Благодаря аппаратным процессорам Groq LPU (Language Processing Unit), 30 секунд аудио распознаются менее чем за полсекунды.
- **Точность:** Модель `whisper-large-v3` от OpenAI является мировым стандартом качества распознавания с идеальной поддержкой русского, английского и других языков, включая технические термины и знаки препинания.
- **Бесплатность:** Groq предоставляет щедрый бесплатный тарифный план (Free Tier), которого более чем достаточно для ежедневной работы.

## 3. Архитектура и принцип работы TTS (Orpheus / Kokoro / Fallback)

```
[ Ответ языковой модели поступает в чат потоком (Streaming) ]
                    │
                    ▼
[ Санитизация текста (VoiceEngine.cleanText) ]
  - Вырезаются XML-теги навыков ToolHub: <hub>...</hub>
  - Вырезаются внутренние блоки памяти GraphMem
  - Блоки кода ```...``` заменяются на мягкую фразу "Код опущен"
  - Удаляются эмодзи, звездочки markdown и спецсимволы
                    │
                    ▼
[ Нарезка на предложения по 150-180 символов ]
  (речь не задерживается до конца ответа, а начинает звучать сразу!)
                    │
                    ▼
[ Запрос к эндпоинту /audio/speech (Kokoro / Orpheus / OpenAI format) ]
      - Body: { model: "kokoro", voice: "sveta", input: chunk }
                    │
          ┌─────────┴─────────┐
     [Успех: 200 OK]    [Ошибка / 429 / Сервер выключен]
          │                          │
          ▼                          ▼
[ Воспроизведение WAV ]   [ Браузерный Web Speech API ]
(HTML5 Audio Queue)       (window.speechSynthesis)
```

### Автоматический Web Speech Fallback:
Если у вас нет запущенного локального сервера Kokoro TTS или превышен лимит стороннего сервиса, плеер **не выдаст ошибку** и **не зависнет**: он мгновенно и прозрачно передаст фразу встроенному в ваш браузер синтезатору речи (Chrome, Edge, Safari, Firefox). Звук будет воспроизведен в любом случае!

## 4. Пошаговая инструкция по настройке за 2 минуты

### Шаг 1: Получение бесплатного ключа Groq API
1. Перейдите на официальный портал: **[https://console.groq.com/keys](https://console.groq.com/keys)**
2. Зарегистрируйтесь или войдите через Google / GitHub аккаунт (карту привязывать **не требуется**).
3. Нажмите кнопку **Create API Key**.
4. Введите любое имя ключа (например, `Lab-Voice`) и скопируйте полученный ключ, начинающийся на `gsk_...`.

### Шаг 2: Ввод ключа в приложении
1. Откройте **Настройки (Settings)** в шапке приложения.
2. Перейдите во вкладку **🎙️ Голос (Voice)** (или откройте правую панель **Context** -> вкладка **Интеграции**).
3. В поле **Groq STT API Key** вставьте скопированный ключ `gsk_...`.
4. Включите тумблер **Голосовой ввод (STT)**.

### Шаг 3: Проверка микрофона (Hold-to-Talk)
1. В поле ввода чата появится фиолетовая иконка микрофона 🎙️.
2. Нажмите и удерживайте иконку микрофона (или клавишу **Пробел**, если включен хоткей).
3. Надиктуйте сообщение (не менее 2 секунд) и отпустите кнопку.
4. Текст моментально появится в поле ввода!

## 5. Справочник параметров и адресов

| Параметр | По умолчанию | Описание |
|---|---|---|
| **STT Base URL** | `https://api.groq.com/openai/v1` | Адрес OpenAI-совместимого эндпоинта транскрибации. Для локального Whisper можно указать `http://localhost:11434/v1` |
| **STT Model** | `whisper-large-v3` | Модель распознавания речи (`whisper-large-v3` или `whisper-large-v3-turbo`) |
| **TTS Base URL** | `http://localhost:8880/v1` | Адрес локального или облачного сервера синтеза речи (OpenAI compatible) |
| **TTS Model** | `kokoro` или `canopylabs/orpheus-v1-english` | Идентификатор модели синтеза речи |
| **TTS Voice** | `sveta` или `hannah` | Голос диктора |
| **Авто-озвучка (Auto-TTS)** | `Выкл` | Автоматически озвучивать каждый входящий ответ ассистента |
| **Хоткей ввода** | `Space` (Пробел) | Клавиша для включения микрофона в режиме рации (Hold-to-Talk) |
