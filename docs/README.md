# Документация объединённой системы: Lab + ToolHub (Full Stack AI Studio & Skill Orchestration Platform)

Добро пожаловать в единый центр технической документации платформы **Lab + ToolHub**.

Данная система представляет собой глубоко интегрированную экосистему полного цикла для исследователей, инженеров и пользователей искусственного интеллекта:
1. **Lab Studio** — клиентский интерактивный рабочий стол (AI Workbench) с поддержкой десятков провайдеров LLM, ветвления контекстных деревьев диалогов, редактора кода Monaco, математического рендеринга LaTeX, точного подсчёта токенов и голосового ввода/вывода.
2. **ToolHub Core** — высокопроизводительный оркестратор навыков и инструментов для автономных агентов с древовидной виртуальной файловой системой категорий, средой изолированного исполнения скриптов на любых языках (Bun, Node, Python, Bash), поддержкой протокола MCP (Model Context Protocol), динамической федерацией хабов и административным пультом управления.

## ⚡ Краткая справка по быстрому старту

```bash
# 1. Установка всех зависимостей экосистемы
bun install

# 2. Инициализация локальной базы данных SQLite
bun run db:generate
bun run db:push
bun run db:seed -- --lang=en --admin-pass=admin --agent-pass=123

# 3. Запуск системы в режиме разработки
bun run dev

# 4. Продуктовая сборка всех модулей
bun run build
```
