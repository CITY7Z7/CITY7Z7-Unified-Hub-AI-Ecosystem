# ADR-002: Лицензирование и авторские права объединённого проекта

> **Статус:** Принято  
> **Дата:** Октябрь 2026  
> **Контекст:** Анализ лицензий обоих исходных репозиториев и определение лицензионной политики объединённой системы.

---

## 1. Анализ лицензий исходных проектов

Было проведено исследование файлов лицензий в обоих исходных репозиториях:

1. **Репозиторий `Talos-popcorn/toolhub`:**
   - Файл: `LICENSE` (34 523 байта)
   - Тип лицензии: **GNU Affero General Public License Version 3 (AGPL-3.0)**
   - Копирайт: Copyright (C) 2007 Free Software Foundation, Inc.

2. **Репозиторий `Talos-popcorn/lab`:**
   - Файл: `LICENSE` (34 523 байта)
   - Тип лицензии: **GNU Affero General Public License Version 3 (AGPL-3.0)**
   - Копирайт: Copyright (C) 2007 Free Software Foundation, Inc.
   - История: Лицензия была явно зафиксирована коммитом `cac64d4` ("docs: add missing AGPL-3.0 LICENSE file").

---

## 2. Лицензионная совместимость

Оба исходных проекта принадлежат одному автору/организации (`Talos-popcorn`) и лицензированы под одной и той же копилефтной лицензией — **AGPL-3.0**.

Следовательно:
- Между проектами отсутствует какой-либо лицензионный конфликт.
- Слияние кодовых баз на 100% легально и не нарушает условий использования.

---

## 3. Решение

1. Объединённая система лицензируется под единой лицензией **GNU Affero General Public License Version 3 (AGPL-3.0)**.
2. В корне объединённого проекта сохраняется оригинальный файл лицензии `LICENSE`.
3. В документации и манифестах `package.json` фиксируется `license: "AGPL-3.0"`.
4. Сохраняются оригинальные авторские права и ссылки на первоисточники `Talos-popcorn`.
